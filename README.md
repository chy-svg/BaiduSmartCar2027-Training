# 任务零 · 热身五题

> M0 阶段入门任务 ｜ 周期 1 周 ｜ 编写语言：Python ｜ 与任务一并行进行
> 五道小题覆盖 Linux 环境下 Python 程序的标准输入输出、字符串处理、循环与条件——这是后续所有飞桨脚本开发的基础功。

## 如何做题

1. 阅读各题题面：`problems/p1-hello-farm/statement.md` 至 `problems/p5-water-tower/statement.md`；
2. 在 `solutions/` 下创建同名解答文件：`p1.py` … `p5.py`（程序从**标准输入**读取数据，向**标准输出**写答案）；
3. 本地自测：仓库根目录运行 `python tools/grade.py`，即时查看逐题判题结果；
4. push 后 GitHub Actions 自动判题，结果见仓库 Actions 页签（绿勾 = 全部通过）。

| 题号 | 题目 | 考点 |

## 说明

- 测试数据在仓库中公开（`problems/*/tests/`），便于本地自测调试；
- 集中验收时会就你的解法现场追问并要求限时修改——硬编码测试点输出无法通过验收；
- 解答文件缺失视为该题未提交。
